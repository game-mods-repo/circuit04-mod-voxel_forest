## Описание мода / Description
Атмосферная лесная локация с воксельным ландшафтом, хвойными деревьями, валунами, поросшими травой холмами и чистым воздухом. Полная поддержка физики, Hand IK и инструментов.

## Установка мода / Installation

### Способ 1: Автоматическая установка через игру
1. Запустите **Circuit 04**.
2. Откройте Главное меню -> **«Моды»** -> вкладка **«Репозиторий»**.
3. Найдите мод **Лесной сектор (Voxel Forest)** и нажмите кнопку **«Установить»**.

### Способ 2: Ручная установка из ZIP
1. Скачайте архив `voxel_forest.zip` из последнего [Релиза](https://github.com/game-mods-repo/circuit04-mod-voxel_forest/releases/latest).
2. Поместите архив или распакованную папку в директорию `mods/` (или `mods/maps/` для карт).
3. В игре во вкладке «Менеджер модов» нажмите кнопку **«Обновить список»**.
